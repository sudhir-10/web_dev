HOTEL MANAGEMENT SYSTEM - QUICK START GUIDE
============================================

WHAT IS THIS?
A complete hotel management web application with authentication, authorization, 
database, and professional web interface. Everything you need to manage a hotel.

QUICK SETUP (3 STEPS)
====================

Step 1: Extract the ZIP file
    - Extract: hotel-management-system.zip
    - Go to the folder: cd hotel-management

Step 2: Install (requires Node.js to be installed)
    - Run: npm install
    - This downloads all required libraries

Step 3: Start the server
    - Run: npm start
    - Open browser: http://localhost:5000

WHAT EACH ROLE CAN DO
=====================

ADMIN:
  ✓ View dashboard with statistics
  ✓ Add, edit, delete rooms
  ✓ Manage all bookings
  ✓ Create and manage users
  ✓ View system revenue and stats

STAFF:
  ✓ View dashboard
  ✓ Manage rooms
  ✓ Manage all bookings
  ✓ Cannot manage users

GUEST:
  ✓ Search for available rooms
  ✓ Make bookings
  ✓ View own bookings
  ✓ Cannot access admin features

MAIN FEATURES
=============

1. AUTHENTICATION
   - Secure login with JWT tokens
   - Password hashing with bcryptjs
   - Remember me functionality

2. ROOM MANAGEMENT
   - Add rooms with type, price, capacity
   - Track room status (available, occupied, maintenance)
   - View all rooms with filters

3. BOOKING SYSTEM
   - Search available rooms by dates
   - Create reservations automatically
   - Auto-calculate total price
   - Track booking status
   - Add special requests

4. USER MANAGEMENT (Admin)
   - Create new users
   - Assign roles (Admin, Staff, Guest)
   - Reset passwords
   - Delete users
   - View statistics

DATABASE TABLES
===============

1. USERS - User accounts, passwords, roles
2. ROOMS - Hotel rooms, types, pricing
3. GUESTS - Guest information
4. BOOKINGS - Reservations and check-in/out dates

All properly connected with relationships and constraints.

TECHNOLOGY USED
===============

Frontend:   HTML5, CSS3, JavaScript
Backend:    Node.js, Express.js
Database:   SQLite3
Security:   JWT, bcryptjs
API:        REST with 30+ endpoints

TROUBLESHOOTING
===============

PORT ALREADY IN USE:
  Run: PORT=3000 npm start

DEPENDENCIES ERROR:
  Run: npm install
  
DATABASE ERROR:
  Run: rm hotel.db
  Then: npm start
  (Database will be recreated)

CAN'T LOGIN:
  - Check email spelling
  - Try: admin@hotel.com / admin123
  - Clear browser cookies
